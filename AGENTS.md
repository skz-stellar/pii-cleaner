# Repository instructions

- Do not add AI credits, AI co-authors, generated-by notices, or AI attribution
  trailers to commit messages, pull requests, documentation, or source files.
- Use the user's Git identity for commits. Do not invent a human co-author.
- Keep sanitization entirely local to the browser; preserve the CSP and the
  no-network checks.
- GitHub Pages deploys the flat `dist/web/` build at `/pii-cleaner/`.
